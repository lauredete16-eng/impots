# Fiscalia — portail fiscal de démonstration (Next.js + Tailwind, 100 % frontend)

    npm install
    npm run dev   # http://localhost:3000

- Nom / domaine : `lib/config.js`
- Logo : `components/Logo.jsx`
- Utilisateurs : `lib/userService.js` (jean / demo1234 — entreprise / demo1234)
- Textes et actualités : `lib/data.js`

Site fictif de démonstration : ne pas le publier comme un vrai site fiscal et ne jamais y saisir de données réelles.
